# 阶段任务清单（个人非营利版）

> 配套文档：[背单词网站建设计划.md](./背单词网站建设计划.md)　|　旧版：`v1-阶段任务清单.md`
> 用法：按阶段推进；每项满足「验收标准」才算完成；依赖未完成不得启动。
> 规模：S（半天内）/ M（1–3 天）/ L（3 天以上，需拆解）
> 状态：☐ 未开始　◐ 进行中　☑ 已完成　✕ 阻塞

## 执行规则

1. **内容先过脚本，再进人工**。`audit-content` 红灯的稿子不进入改写流程。
2. **每篇必须 60 个目标词，且 ≥95% 的词篇内出现 ≥2 次**；不满足不发布。
3. **每周 1–2 篇**是可持续节奏；连续 4 周做不到，缩到 28 篇（中考路线），不硬撑。
4. **任何阶段都可以停**：2 篇、10 篇、28 篇、55 篇都是完整可用的产品。
5. **不加需求**：账号、支付、统计、社区、教师端一律不做；出现即拒绝。
6. 所有内容与数据在 git 里；发布走 GitHub Actions，构建失败不发布。

## 单篇 Definition of Done

一篇短文同时满足以下 10 条，才能把 `status` 改为 `published`：

- [ ] 恰好 60 个目标词；≥95% 的词篇内 ≥2 次，其余 ≥1 次
- [ ] 篇长、句数在所属阶段区间；平均句长不超上限
- [ ] 非目标词 0 个（专名 ≤2 且注）
- [ ] 生词密度 25–32%，目标词出现密度 55–62%
- [ ] 3–5 个句式模板，每个至少复用 3 次
- [ ] 8–12 个搭配已标注
- [ ] 逐句译文准确，默认折叠
- [ ] 8 道题可自动判分，答案唯一
- [ ] TTS 自听不拗口，朗读 70–110 秒
- [ ] 审计全绿，版本号与 changelog 已写

## 每批 Definition of Done（10 篇左右）

- [ ] 覆盖报告、密度分布、复现率三张表更新
- [ ] 审计全绿，无阻断项
- [ ] 作者本人至少完整学过其中 3 篇
- [ ] 词表版本未在批中漂移
- [ ] 发布后 7 天内无严重勘误

## 停止规则

出现以下任一情况，**停止扩篇，先修方法**：

1. Gate 0 的 60 词/篇实测连续两次不达标；
2. 连续 4 周无法完成每周 1 篇；
3. 审计出现系统性问题（如普遍凑词、句式僵硬）；
4. 版权/平台出现无法在 7 天内解决的问题。

停止不是失败。项目在 2 篇、10 篇、28 篇任一节点都是可用的。
