# 中间稿：v2 最少篇数测算（个人非营利版）

> 旧版 v1 的 450 篇测算已作废，保留在 git 历史中。本文件对应 outputs 下的 v2 计划。

## 1. 定位约束

- 一个人维护、零成本、GitHub Pages、无后端、无账号。
- 目标不是「每篇轻松」，而是「总篇数少到让人愿意开始」。
- 允许每篇生词密度大幅提高，但不能退化成词表。

## 2. 变量

| 符号 | 含义 | 取值 |
|---|---|---|
| W | 总词数 | 3,300 |
| k | 每篇生词数 | 待定 |
| N | 篇数 | ceil(W/k) |
| r | 每词篇内出现次数 | 2 |
| g | 非目标词词次占比 | 0.40 |
| L | 篇长 | r·k/(1-g) = 3.33k |

关键：L 与 k 成正比，所以「每句几个生词」基本恒定（约 3 个/句），压缩篇数只会让每篇更长、每次学得更多，不会让局部更难。约束落在「单篇记忆量」和「可背诵长度」，而不是阅读难度。

## 3. 权衡表

| k | N | L | 生词密度 | 判定 |
|---:|---:|---:|---:|---|
| 20 | 165 | 67 | 30% | 目录劝退 |
| 30 | 110 | 100 | 30% | 仍多 |
| 40 | 83 | 133 | 30% | 可接受 |
| 50 | 66 | 167 | 30% | 接近 |
| **60** | **55** | **200** | **30%** | **下限** |
| 70 | 48 | 233 | 30% | 单篇超载 |
| 80 | 42 | 267 | 30% | 背诵崩 |
| 100 | 33 | 333 | 30% | 已是词表 |

## 4. 下限结论

- 单篇记忆上限：k ≤ 60（分两次学，每次约 30 词）。
- 可背诵长度：L ≤ 240。
- 覆盖：N ≥ ceil(3,300/60) = 55。

所以 55 篇 × 60 词 = 3,300。

压到 48 篇要 70 词/篇；长度 233 仍在可背范围，但 70 词超出单篇记忆上限，省 7 篇换来整门课回忆率下降。压到 33 篇要 100 词/篇，已是词表拼接。

## 5. 双路线

- 前 28 篇 = 28 × 60 = 1,680 词位，覆盖中考约 1,650 词 + 30 缓冲。
- 后 27 篇 = 1,620 词。
- 不另编中考套，避免重复内容。

## 6. 代价与补偿

| 代价 | 补偿 |
|---|---|
| 单篇 60 词负荷高 | 分两次学，每次 30 词 |
| 200 词背诵吃力 | 3 段、每段 6–7 句，先分段后背整篇 |
| 篇间复现为零 | 复读旧篇 D1/3/7/16/35 + SRS + 单元混测 |
| 语境单一 | 篇内 2 次 + 8–12 搭配 + 原句回链 |
| 写作难 | 3–5 句式模板 + AI 三稿 + 人工改写 |
| 容错低 | 脚本门禁 + 朗读 + 延迟 7 天发布 + 勘误 |

## 7. 待验证

- 60 词/篇 24 小时回忆能否 ≥40/60
- 200 词朗读是否拗口
- 7 日保持率能否 ≥75%
- 中考词能否全部落进前 28 篇
