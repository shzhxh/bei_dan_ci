# 中间稿：提纲与关键决策（v1，已作废）

> 本文件是 v1（450 篇商业方案）的写作脚手架，**已不适用于 v2**。
> v2 的决策已并入 `outputs/背单词网站建设计划.md`（个人非营利、55 篇、60 词/篇）。
> 保留此文件仅为对照历史；最新测算见 `work/02-词表与覆盖率测算.md`。

## 一、要回答的 7 个问题

1. 词汇怎么分层、怎么选题，覆盖率怎么算？
2. 短文怎么编排，多长、多少词、怎么复现、怎么保证不遗漏？
3. 学习者从进站到学完一轮，路径和页面是什么？
4. 内容怎么生产、怎么控质？
5. 技术上怎么做，分几期？
6. 怎么算成功？
7. 主要风险是什么？

## 二、已定的关键决策（待评审）

| # | 决策 | 结论 | 理由 |
|---|---|---|---|
| D1 | 课程套数 | 主套 S3000（3,300 词 / 300 篇）+ 中考套 J1500（1,650 词位 / 150 篇） | 覆盖两类主用户；J 是低门槛入口 |
| D2 | 词的计量单位 | lemma（词元），派生词单列 | 与词表口径、考纲口径一致 |
| D3 | 每篇新词数 | 11 个 | 记忆负荷与篇长的平衡点 |
| D4 | 复现要求 | 5★ 正文 3 次；4★/3★ 正文 2 次；复习模块另计 | 兼顾密度与保持率 |
| D5 | 覆盖率口径 | type 覆盖（词表）与 token 覆盖（文本）分开算 | 用户说的 95% 是 token 覆盖 |
| D6 | 不遗漏机制 | 分配账簿 + CI 硬门禁 + 看板三闸 | 只靠人工必然漏 |
| D7 | 背诵 | 四阶脚手架（全文→挖空→首字母→回译），做成第一功能 | 用户核心诉求是"背短文" |
| D8 | 技术 | Astro 静态站 + 岛屿交互 + 本地进度；P2 再加账号 | 内容型站点，SEO/成本/离线优先 |
| D9 | 释义与例句 | 全部自建；星级只作选题参考 | 规避词典版权 |
| D10 | 首期不做 | 社区、UGC、AI 对话、口语评分 | 不扩大战线 |

## 三、结构

摘要 → 产品定义 → 词汇体系 → 短文体系 → 学习路径与页面 → 内容生产与 QC → 技术 → 分期 → 成功标准 → 风险 → 附录
