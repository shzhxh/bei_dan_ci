# 阶段任务清单（个人非营利版 · v4）

> 配套文档：[背单词网站建设计划.md](./背单词网站建设计划.md)　|　旧版：`v1-阶段任务清单.md`、`v2-阶段任务清单.md`、`v3-阶段任务清单.md`
> 用法：按阶段推进；每项满足「验收标准」才算完成；依赖未完成不得启动。
> 规模：S（半天内）/ M（1–3 天）/ L（3 天以上，需拆解）
> 状态：☐ 未开始　◐ 进行中　☑ 已完成　✕ 阻塞

## 执行规则

1. **内容先过脚本，再进人工**。`audit-content` 红灯的稿子不进入改写流程。
2. **主线每篇 59 或 60 个目标词，补漏每篇 57 或 58 个**，与各自账簿一致；≥95% 的词篇内出现 ≥2 次；不满足不发布。
3. **每周 1–2 篇**是可持续节奏；连续 4 周做不到，缩到 27 篇（中考路线），不硬撑。
4. **任何阶段都可以停**：2 篇、10 篇、27 篇、55 篇都是完整可用的产品。
5. **不加需求**：账号、支付、统计、社区、教师端一律不做；出现即拒绝。
6. 所有内容与数据在 git 里；发布走 GitHub Actions，构建失败不发布。

## 单篇 Definition of Done

### 主线篇（p01–p50）

- [ ] 恰好 59 或 60 个目标词，且与 `assignment.tsv` 一致；≥95% 的词篇内 ≥2 次
- [ ] 篇长、句数在所属阶段区间；平均句长不超上限
- [ ] 非目标词 0 个（专名 ≤2 且注）
- [ ] 生词密度 28–32%，目标词出现密度 55–63%
- [ ] 可用词性：可作名词 ≥30、可作动词 ≥20、可作形/副 ≥10
- [ ] 3–5 个句式模板，每个至少复用 3 次
- [ ] 8–12 个搭配已标注
- [ ] 逐句译文准确，默认折叠
- [ ] 8 道题可自动判分，答案唯一
- [ ] TTS 自听不拗口，朗读 70–110 秒；审计全绿，版本号与 changelog 已写

### 补漏篇（b01–b05）

- [ ] 恰好 57 或 58 个目标词，全部 `stars=0 / star_source=zhongkao`，且与 `assignment-supplement.tsv` 一致
- [ ] 篇长 190–195 词、18–19 句、平均句长 ≤11、3 个主线已出现的句式模板
- [ ] 回引 15–25 个 p01–p22 已学词作为骨架；非目标词 0
- [ ] 生词密度 28–32%，目标词出现密度 55–63%
- [ ] 可用词性：名 ≥30、动 ≥20、形副 ≥10
- [ ] 8–12 个搭配；逐句译文；8 题；TTS 自听不拗口
- [ ] 页面标「中考补漏 · 无星级」+ 路线位置（23–27）
- [ ] 审计全绿，版本号与 changelog 已写

## 每批 Definition of Done（10 篇左右）

- [ ] 覆盖报告、密度分布、复现率三张表更新
- [ ] 审计全绿，无阻断项
- [ ] 作者本人至少完整学过其中 3 篇
- [ ] 词表版本未在批中漂移（主线 2,953 / 50 组；补漏 289 / 5 组）
- [ ] 发布后 7 天内无严重勘误

## 停止规则

出现以下任一情况，**停止扩篇，先修方法**：

1. Gate 0 的主线 59–60 或补漏 57–58 词/篇实测连续两次不达标；
2. 连续 4 周无法完成每周 1 篇；
3. 审计出现系统性问题（如普遍凑词、句式僵硬）；
4. 版权/平台出现无法在 7 天内解决的问题。

停止不是失败。项目在 2 篇、10 篇、27 篇任一节点都是可用的。
