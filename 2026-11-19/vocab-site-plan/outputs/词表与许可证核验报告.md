## 0-C. v5 写作参数变更（数据不变）

v5 不新增词、不改篇数、不动双轨与中考路线，只调整正文写法与验收阈值：

| 维度 | v4 | v5 |
|---|---|---|
| 篇内复现 | 每词 ≥2 次（≥95% 达标） | **每词 ≥1 次**；允许自然重复，不强制 2 次 |
| 篇长 | 主线 197–200；补漏 190–195 | **统一 280–320 词**（补漏 280–315） |
| 目标词词次密度 | 55–63% | **18–22%** |
| 唯一生词密度 | 约 30% | **18–22%（典型 18–20%）** |
| 句长 | 8–12，阶段上限 11–15 | **8–14 词/句**；每句 2–4 个生词 |
| 句数 | 18–21（补漏 18–19） | **24–28（补漏 29–32）** |
| 文体 | 允许配对回环、同句反说 | **连贯叙事**；禁用配对回环与同句反说 |

对数据的影响：**无**。`lexicon.json`（2,953）、`supplement.json`（289）、`zhongkao.json`（1,547）、`assignment.tsv`（2,953 行）、`assignment-supplement.tsv`（289 行）与 `validation.json` 均保持 v4 状态，无需重建；`validate_lexicon.py` 校验的是词表、分篇与路线，不涉及正文写法，复跑仍 `ok: true`。

对构建门禁的影响：`audit-content` 的篇内出现阈值从「≥95% ≥2 次」改为「100% ≥1 次」；新增 `new_density ∈ [0.18, 0.22]`（目标 18–20%）、`target_token_density ∈ [0.18, 0.22]`、`sentences ∈ [24, 28]`（补漏 `[29, 32]`）、`8 ≤ 句长 ≤ 14`、配对回环/同句反说检测。数据层校验不变，正文层门禁收紧的是密度和叙事一致性。

### 1.3 实测星级分布（原始行）

| 星级 | 原始行数 | 清洗后可用头词 |
|---|---:|---:|
| 5★ | 630 | 600 |
| 4★ | 1,009 | 967 |
| 3★ | 1,418 | 1,386 |
| 2★ | 3,036 | —（几乎全是屈折/派生） |
| 1★ | 7,540 | —（几乎全是屈折/派生） |

原始 5★/4★/3★ 合计 3,057，清洗后 2,953。计划里的 680/1,040/1,580 是柯林斯官方分层的公开口径，**ECDICT 并没有完整收录这 3,300 个词条**：3★ 少 162 行，4★ 少 31 行，5★ 少 50 行，再叠加专名、词组、屈折、无释义的过滤，最终差 347。

### 1.4 两个必须知道的数据噪声

1. **`collins` 按词条/义项标注，不完全按词频。** 例如原始字段里 `take` 标 1★、`place`/`case` 标 2★，而它们的 BNC 排名分别在 51/162/139 左右。直接按星级选词会漏掉极常用词。本次的兜底是：所有 `zk` 词无条件保留，且用 BNC/FRQ 做同层排序。
2. **`pos` 字段大多为空。** 直接读 `pos` 只能覆盖少数词条；本次改为解析 `translation` 每一行的词性前缀（`n.` / `v.` / `a.` / `ad.` …）得到多词性，但仍不是词典级精度。

## 2. 清洗口径

按顺序执行，命中即剔除：

| 步骤 | 规则 | 剔除量 |
|---|---|---:|
| 1 | 只保留 `^[a-z][a-z-]{1,23}$`；非 `zk` 词最短 3 字母 | 405,124 |
| 2 | 必须有中文释义 | 98,454 |
| 3 | 剔除纯屈折：首行为 `pl.` 或“X的过去式/过去分词/现在分词/第三人称单数/复数/比较级/最高级”；剔除规则复数（`apple`+`s`） | 28,891 |
| 4 | 无星级且无考纲标签的词不进入候选 | 223,689 |
| 5 | 同形词按“星级高、义项多”保留一条 | 0（无同形重复） |

> 以上数字是顺序过滤的命中数，不可相加为总行数。

保留的词条带 `senses`（最多 4 条，含词性）、`pos`（多词性并集）、`stars`、`star_source`、`exams`、`freq`、`forms`、`phonetic`。

## 5. 分配与覆盖率口径

### 5.1 已满足的硬约束

| 约束 | 结果 |
|---|---|

| 每词有中文释义/词性/篇目 | ✅ 校验通过 |

### 5.2 未满足或需修订的规则

**词性配比 22 名 / 22 动 / 16 形副：按主导词性不可行。**

- 实测可用词性（一个词可多属）：名词 2,387、动词 1,492、形容词 897、副词 292。
- 按主导词性：名词 2,208、形容词 460、动词 340、副词 131。
- 55 篇平均：名词约 40、动词约 6（主导）/27（可用）、形副约 11–16。
- 名词供给是动词的 6 倍，硬凑 22/22/16 会把大量名词当动词用，或反复使用同一批动词。

**已采纳（v3 起，v4/v5 沿用）**：词性规则改为"可用词性下限"——每篇可作名词 ≥30、可作动词 ≥20、可作形容词/副词 ≥10，同一词可重复计入，不再要求 22/22/16 互斥配比。该规则已同步到计划 v5.0 §2.7/§3.1/§4.5 与任务清单 P0-04/P0-08 的验收标准。

**同一语义场 ≤15 词：未自动校验。** ECDICT 没有语义场字段，当前只能靠人工在 P0-03 分组复核时检查；数据侧不谎称已满足。

**文本覆盖率 92–95%：未实测。** 需要通用语料（如 Brown/COCA 样本）才能算 token 覆盖率，当前只保证词表覆盖 2,953 词本身。

## 9. 结论

1. **当前数据可用（v4 结构，v5 沿用）**：主线 2,953 词全部为 Collins 3–5★，50 篇（3×60 + 47×59）；补漏 289 词全部为 `zk` 无星级词，5 篇（4×58 + 57）；站点合计 3,242 词 / 55 篇。主线与补漏同族词均 0 冲突，校验脚本 `ok: true`。
2. **中考 100% 覆盖已落数据**：路线 27 篇 = 主线 p01–p22（1,258 词）+ 补漏 b01–b05（289 词）= 1,547 词，`zhongkao.json` 用 `route_index` 1–27 标注；1,258 / 1,547 = 81.3% 主线 + 289 / 1,547 = 18.7% 补漏。
3. **来源不混算**：主线 `star_source=collins`、`set=s3000`；补漏 `stars=0`、`star_source=zhongkao`、`set=zk-supplement`。补漏词不进入星级统计，页面必须标“中考补漏 · 无星级”。
4. **主线未被 v4/v5 打乱**：`lexicon.json` 与 `assignment.tsv` 相对 v3 逐字节一致（sha256 相同），补漏以独立文件追加，主线 50 篇编号、分组、内容均未改动；v5 只改写作参数，未触碰任何数据文件。
5. **偏差已量化**：ECDICT 实际收录 1,547 个有效 `zk` 头词，与早期假设 1,650 差 103，属数据源缺口；对外只承诺“ECDICT 口径的 1,547 词 100% 覆盖”。
6. **许可证可走**：ECDICT 为 MIT，保留声明即可；复合来源与柯林斯星标仍需按第 7 节做保守处理。
7. **下一步**：按计划 v5.0 写 2 篇样篇（p01 + b01），正文按 280–320 词、每词 ≥1 次、密度 18–22%、连贯叙事的 v5 规格；分组已由脚本完成，剩余人工复核项是语义场（ECDICT 无语义场字段）、释义种子质量与补漏篇主题。
