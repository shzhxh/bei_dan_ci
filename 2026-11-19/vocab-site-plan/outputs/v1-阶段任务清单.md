# 阶段任务清单（可直接执行）

> 配套文档：[背单词网站建设计划.md](./背单词网站建设计划.md)
> 用法：按阶段顺序推进；每项任务满足「验收标准」才算完成；跨阶段任务可并行，但依赖项未完成不得启动。
> 规模：S（半天内）/ M（1–3 天）/ L（3 天以上，需拆解）
> 状态：☐ 未开始　◐ 进行中　☑ 已完成　✕ 阻塞

## 执行规则

1. **内容任务必须先过脚本，再进人工审**。`audit-content` 红灯的稿子不进审校队列。
2. **每批内容上线前冻结词表版本**，冻结后只允许修 bug，不允许改词表。
3. **任何阶段不得跳过出口标准**。未达标就缩范围或返工，不向下游传递。
4. **每批 50 篇结束后复盘一次**：单位成本、缺陷率、复现达标率、用户错题率。
5. 任务状态在看板更新，阻塞项当天上报。

## 单篇 Definition of Done

一篇短文只有同时满足以下 10 条，才能把 `status` 改为 `published`：

- [ ] 11 个目标词全部命中，且每个在篇内出现 ≥2 次
- [ ] 生词密度在级别上限内（S ≤6%，J ≤7.5%）
- [ ] 超纲词 ≤2 个且全部有中文注
- [ ] 句长与 Flesch 指标在级别区间
- [ ] 1 个主语法点，无未教语法
- [ ] 3–5 个搭配已标注
- [ ] 译文准确、无增删
- [ ] 8 道题可自动判分，答案唯一
- [ ] 音频句级对齐，抽听无错读
- [ ] 双人审校零阻断项，`audit-content` 全绿

## 每批（30–50 篇）Definition of Done

- [ ] 覆盖率、复现达标率、密度分布三张报表更新
- [ ] 缺陷率 <1/千词，问题按类型归档
- [ ] 单位成本较上批不上升（或上升有解释）
- [ ] 词表版本未在批中漂移
- [ ] 用户侧抽 5 篇做可用性走查

## 每期评审模板（5 问）

1. 本期承诺的交付，完成了多少？未完成的卡在哪？
2. 出口指标是否达成？未达成的根因是什么？
3. 内容质量与成本的变化趋势如何？
4. 下一期范围要不要调整（扩/缩/换）？
5. 有哪些假设被证伪，需要改规范或改计划？
